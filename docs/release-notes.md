# OR-Tools v0.1.0

First native binary release for DuckDB 1.4.5, 1.5.6 and 2.0.0.

- Native CP-SAT integer optimization and GLOP linear optimization from SQL.
- Relational allocation with shared capacity and demand across input chunks.
- Validation, cancellation, assumption-core diagnostics, and typed solver results.
- Twelve version/platform packages for Linux and macOS on x86-64 and ARM64.
- Bundled runtime dependencies, source/license notices, build receipts, and SHA-256 checksums.
- Each package passes native SQL tests, dependency audits, excluded-backend checks, and relocated CP-SAT/GLOP solves before publication.

Archives are unsigned. Load only the package matching your DuckDB version and platform, with unsigned extensions enabled. Keep the extension and its bundled lib directory together.
